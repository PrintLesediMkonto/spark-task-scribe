# AI Productivity Hub

Smart Email Generator Create an AI email generator that allows users to: Enter the purpose and details of an email. Select a tone: Formal, Friendly, Professional, Persuasive, Apologetic, or Casual. Select the email length. Generate a professional email. Generate subject-line suggestions. Edit, copy, regenerate, and clear the email.

Meeting Notes Generator Create an AI meeting-notes summarizer where users can: Paste or type meeting notes. Generate a concise summary. Extract key discussion points. Identify decisions made. Extract action items. Identify responsible people. Identify deadlines and follow-ups. Edit, copy, regenerate, download, and clear results.

AI Task Planner / Scheduler Create an AI task planner that allows users to: Add tasks. Set priority: High, Medium, or Low. Add deadlines. Add estimated completion time. Choose Daily or Weekly planning. Automatically prioritize tasks. Generate an organized schedule. Mark tasks as completed. Edit, delete, reorder, and reschedule tasks. Display task progress. Dashboard Create a single dashboard containing: Smart Email Generator Meeting Notes Generator AI Task Planner Use a clean, professional and modern design with responsive layouts for desktop, tablet, and mobile. Important Requirement — No Authentication Do NOT include authentication of any kind. No sign-up page. No login page. No registration. No passwords. No user accounts. No authentication middleware. Users should be able to open the website and immediately use all three tools. Prompt Engineering Use strong AI prompts for each feature. Each prompt should: Define the AI's role. Provide clear context. Specify the required output format. Produce useful and structured results. Handle incomplete or unclear information. Avoid unnecessary or invented information. Responsible AI Add a Responsible AI section explaining that: AI-generated content should be reviewed before use. Users should avoid entering sensitive personal information. AI can make mistakes. Human judgment remains important. User Experience Include: Clear navigation. Attractive cards. Simple forms. Loading indicators. Error handling. Empty states. Copy buttons. Regenerate buttons. Clear/reset buttons. Responsive design. Sample data for testing. Goal Build one cohesive AI productivity application that demonstrates practical AI implementation, strong prompt engineering, real-world problem solving, productivity improvement, and responsible AI usage, while requiring no authentication whatsoever.
